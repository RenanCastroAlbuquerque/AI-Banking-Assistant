# AI Banking Assistant

Projeto desenvolvido para a CP4 da FIAP, utilizando inteligência
artificial e arquitetura multi-agente para simular um sistema de
atendimento bancário.

## 🤖 Sobre o projeto

O sistema utiliza agentes especializados para realizar o atendimento
de clientes de um banco fictício.

O agente principal é responsável pelo atendimento e pode direcionar
a solicitação para agentes especializados.

### Funcionalidades

- Atendimento bancário por IA
- Consulta de saldo
- Realização de PIX
- Agentes especializados
- Handoff entre agentes
- Histórico de conversa

## 🛠️ Tecnologias

- Python
- OpenAI Agents SDK
- Google Colab
- OpenAI API


## 🚀 Como executar

1. Clone o repositório
2. Instale as dependências
3. Configure sua chave da OpenAI
4. Execute o notebook

## 🔐 Configuração da API Key

A chave da API **não deve ser colocada diretamente no código**.

Configure a variável de ambiente:

`OPENAI_API_KEY`
